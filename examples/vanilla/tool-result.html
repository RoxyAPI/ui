Render an AI tool result

Your model calls a Remote MCP tool at roxyapi.com/mcp/{domain} and hands back a tool name and a JSON string. Paste both below and the page renders the component that draws that response.

Tools are named for their method and path, so a three card spread is post_tarot_spreads_three_card and a daily card is post_tarot_daily. A name a host prefixed with its own server works too.
